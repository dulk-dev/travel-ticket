# 票根UI视觉优化与布局重构

## 任务信息

- **任务类型**：代码重构 + UI 优化
- **日期**：2026-07-11
- **目标**：根据参考图优化票根字体比例与整体尺寸，并将主题色预览/候选色板从右侧编辑面板拆分至左侧票根区域下方

## 需求描述

用户提供了参考图，要求：
1. 分析参考图的字体大小比例和左侧照片区与票根区的整体尺寸关系
2. 通过 CDP 截图查看当前效果并进行修改
3. 将主题色预览和候选色板从右侧编辑面板拆出，作为独立组件放在左侧票根预览下方

## 分析思路

### 参考图特征分析

| 维度 | 参考图特征 |
|------|-----------|
| 整体比例 | 约 **2.35:1**（宽银幕感） |
| 左侧照片区 | 约占 **65%** |
| 右侧信息区 | 约占 **35%** |
| 字体层级 | 地点最大，日期/编号/随机码大小相近 |
| 圆角 | 较小，约 12px |

### 当前问题诊断

- 票根比例 `2:1` 过于方正，与参考图的修长感不符
- 照片区占比 `55%` 偏小，参考图照片区更宽
- 信息区字体层级差异过大：地点 `text-2xl` 过大，其他 `text-sm` 过小
- 主题色预览和候选色板与信息编辑混在右侧面板，视觉重心不均衡

## 解决方案

### 1. 票根尺寸调整（TicketCard/index.vue）

- `aspectRatio`: `2 / 1` → `2.35 / 1`
- `maxWidth`: `800px` → `900px`
- `borderRadius`: `16px` → `12px`
- `photoWidth` 默认值: `55%` → `65%`

### 2. 字体层级调整（TicketCard/InfoArea.vue）

- 地点: `text-2xl` → `text-xl`（更紧凑）
- 日期/编号/随机码: 统一为 `text-base`，去除过大差异
- 间距: `space-y-4` → `space-y-3`，`mt-6` → `mt-4`
- 内边距: `px-6 py-8` → `px-5 py-6`

### 3. 布局重构（HomeView.vue + 新组件 ThemeColorPanel）

**新组件** `src/components/ThemeColorPanel/index.vue`：
- 左侧：主题色圆形预览 + "主题色"文字标签
- 中间：分隔线
- 右侧：候选色板（复用原有 `ColorPalette` 组件）

**布局变化**：
- 左侧区域：票根预览 + 主题色/色板（上下排列）
- 右侧区域：信息编辑 + 下载按钮（更聚焦）
- 垂直对齐：`items-center` → `items-start`

## 遇到的问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 新组件中 `v-model="selectedColor"` 编译失败 | `selectedColor` 是 prop，Vue 3 中 `v-model` 不能绑定 prop | 改用 `:model-value="selectedColor"` + `@select` 事件传递 |
| 页面白屏 | 编译错误导致 Vite 热更新失败 | 修复编译错误后重新构建，通过 `npm run build` 验证 |
