# 票根实物化缺口与照片内嵌改造

## 执行信息

- **任务类型**：新增功能（UI 实物化）
- **日期**：2026-07-20
- **目标**：参考实物票根照片，为票根新增复合镂空缺口（左右大缺口、裁剪线上下小缺口、两缘细小切口），并让照片区内嵌于票根（padding 间距 + 圆角）

## 需求描述

以实物票根照片为目标，实现四类形态特征：

1. 裁剪线位置上下两个小半圆缺口
2. 票根最左侧新增半圆大缺口（与右侧对称）
3. 左右两侧大缺口四周成排细小切口
4. 照片上传区域与票根保持 padding 间距，照片区域圆角

## 分析思路

原实现用单层 `radial-gradient` mask 只能切一个右侧缺口，无法表达复合镂空。沿用项目中打孔齿孔的位图烘焙思路（`bakePerforationTile`），将整个票根轮廓烘焙为 Canvas 位图 mask：黑色 = 保留、透明 = 镂空，一次成型所有缺口/切口，且与 html2canvas 导出兼容性和旧实现一致。照片内嵌通过「外层容器 padding + 内层圆角 overflow-hidden 包裹 PhotoArea」实现。

## 解决方案

### 位图轮廓 mask（`bakeTicketMask`）

- 3x 分辨率烘焙，按 `宽x高@照片占比` 键控缓存；`mask-size: 100% 100%` 适配实际渲染尺寸
- 左右大半圆缺口：半径 `H×6%`（必须小于照片 padding `H×7.5%`，保证不裁到照片）
- 裁剪线上下小半圆缺口：半径为大缺口一半，x = `照片占比 × W + 6px` 对齐裁剪线条带中心（桌面 65% / 移动 58% 均适配）
- 两缘细小切口：固定种子伪随机（同尺寸烘焙结果一致），整排参数预生成一次、左右镜像共用
  - 半圆咬口为主（85%），偶发小三角口（15%，尺寸 ×0.6、深度 ×0.75）
  - 深度高度一致（2.2%~2.6% H），尺寸波动 ±10%，位置抖动 ±5% 间距，间距 H×6.2%

### 照片区内嵌

- `photoPadding = max(14, H×7.5%)`、`photoRadius = max(10, H×4%)`，随票根高度等比缩放
- 纸纹覆盖层一并移入内层圆角容器

## 迭代过程（共五轮）

| 轮次 | 用户反馈 | 修正 |
|------|----------|------|
| 1 | （初版实现） | 复合 mask + 照片内嵌落地 |
| 2 | 大缺口裁到照片；切口太大太规则 | 大缺口半径 H/10→H×6%，padding 5.5%→7.5%；切口改为圆/三角/短槽混合随机 |
| 3 | 切口数量要多、三角口要更小 | 间距 9.5%→6.2%；形状分布 50/25/25，三角口 ×0.55/×0.7 |
| 4 | 切口应「平衡对称、深度一致」如多票撕线，毛刺仅 1-2 处；现状像被老鼠咬 | 取消短槽，深度/尺寸/位置高度一致，左右镜像对称；毛刺降为每侧至多 1 处 |
| 5 | 毛刺效果不好，去掉 | 移除毛刺逻辑，仅留半圆咬口 + 偶发小三角口 |

## 遇到的问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 大缺口裁到照片 | 缺口半径（H/10）大于照片 padding（5.5%） | 缺口半径降为 H×6%，padding 升至 H×7.5%，两者同为高度比例、任何尺寸成立 |
| 切口像「被老鼠咬」 | 形状/尺寸/深度随机范围过大，毛刺过多 | 收窄随机范围、左右镜像对称、毛刺从 30%/切口 降为每侧至多 1 处，最终完全移除 |
| Playwright 脚本无法写文件 | 沙箱无 require / 动态 import | 改用 SVG 测试图（`scripts/test-photo.svg`）直接上传验证 |
