# 票根纸张纹理功能

- **任务类型**：新增功能（含四轮迭代修复）
- **日期**：2026-07-18
- **目标**：让票根呈现真实纸张质感，支持布纹纸、棉卡纸、水彩纸、珠光纸、羊皮纸五种纸质切换

## 实现过程

### 需求描述

票根原为纯色平涂样式，希望呈现纸张纹理以逼近现实世界质感。用户提供了五种目标纸质的参考图：布纹纸、棉卡纸、水彩纸（艺术纹理纸）、珠光纸、羊皮纸。

### 技术方案决策（clarify 阶段）

候选路线：真实纹理图 vs 程序化模拟 vs 直接贴图叠加。关键约束来自代码现状：

- 票根底色是**动态主题色**（从照片提取 + 用户可换），纹理必须能与任意颜色叠加；
- 导出链路是 **html2canvas**，不支持 `mix-blend-mode`、CSS/SVG 滤镜，混合模式方案导出必失真。

**最终方案（路线 A）**：灰度纹理 tile + Canvas 运行时烘焙——离屏 Canvas 将纹理与主题色做正片叠底，输出彩色纹理 data URL 作为背景。烘焙产物是普通位图，导出 100% 保真。纹理整票覆盖：底色区/信息区/裁剪线用烘焙结果，照片区叠加低透明度灰度纹理层，珠光纸额外叠加渐变层。

### 核心实现

- `usePaperTexture.ts`：纹理加载 + 烘焙管线，结果按「纸种|颜色」缓存，桌面/移动两个票根实例共享
- `PaperTexturePanel/`：纸质选择面板（5 种纸 + 无纹理，默认水彩纸）
- `TicketCard/index.vue`：接入烘焙背景、照片纹理覆盖层、珠光渐变层
- `src/assets/textures/`：5 张 512×512 灰度可平铺 tile（18–80KB/张）

烘焙核心代码：

```ts
const canvas = document.createElement('canvas')
canvas.width = canvas.height = TILE_SIZE
const ctx = canvas.getContext('2d')
ctx.fillStyle = color
ctx.fillRect(0, 0, TILE_SIZE, TILE_SIZE)
ctx.globalCompositeOperation = 'multiply'
ctx.drawImage(img, 0, 0, TILE_SIZE, TILE_SIZE)
return canvas.toDataURL('image/png')
```

### 素材来源

- 水彩纸、棉卡纸初版：Wikimedia Commons CC0 扫描图（`Papier aquarelle 100% coton, grain fin`、`Papier aquarelle en cellulose`），经中值滤波去杂质 + flat-field 亮度均衡处理
- 珠光纸：程序化细颗粒 + CSS 渐变高光
- 布纹纸：程序化生成（Commons 搜索命中率低且触发 429 限流）
- 羊皮纸：水彩扫描图 + 程序化低频斑驳

## 四轮迭代修复

| 轮次 | 问题 | 原因 | 解决方案 |
|------|------|------|----------|
| 1 | 布纹纸像"格子布"，与实物差距大 | 规则横线 + 24px 链线过于机械 | numpy 平纹编织模拟：2px 线径、奇偶格经纬交替、每线独立明暗抖动 |
| 1 | 棉卡纸有明显拼接分界线 | 镜像平铺在轴处复制整行/列 + 低频斑块未均衡 | flat-field 半径 0.15→0.3，去除低频斑块 |
| 2 | 水彩/棉卡仍有横贯整票的直线 | 镜像对称轴处是**同一行像素的复制**（255 行==256 行） | 半块 256→257px 再裁剪，拼接处读取相邻像素，消除复制行 |
| 3 | 棉卡纸边界线仍明显 | 中低频斑驳经镜像后在对称轴形成带状结构，镜像路线无解 | 弃用扫描图，改**可平铺程序化值噪声**：5 倍频叠加、网格周期采样、y 向 2 倍拉伸模拟纤维，构造性无缝零对称 |
| 3 | 珠光纸上传照片后效果不明显 | 仅白色高光带，过于含蓄 | 叠加彩虹色泽渐变层（粉→金→绿→蓝→紫，alpha 0.10–0.13，125° 对角），整票覆盖 |

## 验收方式

每轮均通过 Playwright 驱动 Chrome 实际验证：五种纸逐一截图、主题色切换重烘焙、html2canvas 导出保真、移动端布局；第三轮起按用户要求以**原图分辨率局部放大**确认拼缝细节。证据归档于 `evidence/` 下四个文件夹（20260718-1048 / -1122 / -1135 / -1153）。
