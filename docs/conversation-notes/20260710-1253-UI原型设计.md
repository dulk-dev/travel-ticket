## 背景

在交互设计阶段确认了上传交互、取景框策略、信息来源、主题色提取、下载格式等核心机制后，本次讨论聚焦 UI 原型的具体布局与视觉呈现。目标是产出可直接指导前端实现的电脑端 UI 原型图。

---

## 讨论过程

### 问题 1：页面整体布局结构

- **讨论点**：页面应如何分区？顶部是否需要导航栏？
- **方案对比**：
  - 方案 A：顶部导航栏（品牌 + 上传按钮 + 教程）+ 左侧照片编辑区 + 右侧信息编辑区
  - 方案 B：极简布局，直接左右分栏，无顶部导航
- **最终决策**：选择方案 B，整体追求零学习成本，用户一进入页面就能理解操作方式。删除顶部导航栏中的"上传照片"和"使用教程"按钮。

### 问题 2：左侧预览区的状态呈现

- **讨论点**：左侧区域在无图/有图时是否保持同一形态？
- **方案对比**：
  - 方案 A：无图时显示上传区，有图时显示照片，票根信息在右侧独立显示
  - 方案 B：无论有无图片，左侧始终呈现完整票根形态（照片区 + 信息区），右侧仅作编辑控制
- **最终决策**：选择方案 B，页面始终以"状态 C"（完整票根）呈现。未上传时左侧照片区显示上传按钮，票根信息区使用 mock 数据填充；上传后照片区显示真实照片，信息区可编辑。

### 问题 3：整体背景色的处理

- **讨论点**：网页背景色如何与票根关联？
- **最终决策**：整个网页的背景色就是最终票根的背景板颜色。未上传时为默认米白色，上传后根据照片自动提取主题色并低饱和处理。

### 问题 4：右侧编辑区的内容范围

- **讨论点**：右侧应保留哪些控件？
- **最终决策**：右侧仅保留：主题色预览条、候选色板（6 个）、四个可编辑字段（地点/时间/编号/随机码）、装饰性条形码、下载按钮。删除取景框比例切换（横版/竖版/方形）。

### 问题 5：未上传时的 mock 数据规则

- **讨论点**：未上传时票根信息区的 mock 值如何生成？
- **最终决策**：
  - 地点：根据访问者 IP 定位
  - 时间：当前时间
  - 编号：当前日期格式 `YYMMDD`
  - 随机码：随机 5 位字母数字

### 问题 6：候选色板的激活状态

- **讨论点**：未上传时候选色板如何呈现？
- **最终决策**：未上传时禁用，显示 6 个灰色空心圆圈；上传后激活，显示 6 个彩色可点击色块。

### 问题 7：上传按钮的视觉样式

- **讨论点**：上传按钮放在哪里？如何提示拖拽？
- **最终决策**：上传按钮位于左侧照片区域内居中，外围用虚线框标识可拖拽区域，底部标注支持 `JPG / PNG` 格式。

### 问题 8：移动端布局与票根信息排列

- **讨论点**：移动端如何适配？票根信息是纵向还是横向排列？
- **方案对比**：
  - 方案 A：上下结构，上方票根预览区（照片纵向堆叠信息），下方编辑区
  - 方案 B：上下结构，上方票根预览区（照片 + 横向排列信息），下方编辑区
- **最终决策**：选择方案 B。移动端采用上下分栏：上方为票根预览区（照片在左，票根信息在右横向排列），下方为可滚动编辑控制区。票根信息不精简，字号适当缩小以适应横向空间。

---

## 关键思路

1. **全状态一致性**：页面始终以完整票根形态呈现，避免状态切换带来的认知跳跃。未上传时用 mock 数据"占位"，让用户提前感知最终效果。
2. **背景即票根**：网页背景色与票根背景色统一，上传后整个页面氛围随照片主题色变化，增强沉浸感。
3. **零学习成本**：删除所有非必要控件（顶部导航、比例切换），只保留最直观的操作路径：上传 → 微调 → 下载。
4. **渐进式激活**：未上传时右侧编辑区保持"可预览但不可改"的状态，上传后逐步解锁编辑能力，引导用户完成操作流程。

## 设计确认清单

| 项目 | 确认内容 |
|------|---------|
| Mock 数据 | 地点：IP 定位；时间：当前时间；编号：`YYMMDD`；随机码：5 位字母数字 |
| 默认背景色 | 米白色 `#F5F0EB` |
| 上传按钮 | 照片区域内居中，虚线框提示拖拽区域，底部显示 `JPG / PNG` 格式标签 |
| 候选色板 | 6 个色块，未激活时灰色空心圆圈，上传后激活为彩色可点击 |
| 字段编辑 | 地点/时间/编号/随机码均以 input 框呈现，支持实时编辑 |
| 下载按钮 | 右侧底部（电脑端）/ 编辑区底部（移动端），支持 PNG / JPG 两种格式 |
| 删除元素 | 顶部导航栏（上传/教程按钮）、取景框比例切换（横/竖/方形） |

## 预期结果

- **电脑端**：左右分栏，左侧始终呈现完整票根预览（照片区左 + 信息区右），右侧为主题色与信息编辑面板
- **移动端**：上下分栏，上方为票根预览区（照片左 + 信息右横向排列），下方为可滚动编辑控制区
