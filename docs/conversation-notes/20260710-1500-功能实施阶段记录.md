## 实施过程

### 1. 项目初始化

- 使用 Vite + Vue 3 + TypeScript 初始化项目
- 集成 Tailwind CSS 4.x
- 安装核心依赖：html2canvas、jsbarcode
- 配置路径别名 `@/` 指向 `src/`

### 2. 组件开发

| 组件 | 文件 | 功能说明 |
|------|------|----------|
| TicketCard | `src/components/TicketCard/index.vue` | 票根卡片主体，整合照片区和信息区 |
| PhotoArea | `src/components/TicketCard/PhotoArea.vue` | 左侧照片区域，支持上传、拖拽、缩放、拖动 |
| InfoArea | `src/components/TicketCard/InfoArea.vue` | 右侧票根信息展示 |
| ColorPalette | `src/components/ColorPalette/index.vue` | 候选色板（6 色），支持禁用/激活状态 |
| InfoEditor | `src/components/InfoEditor/index.vue` | 票根信息编辑（地点/时间/编号/随机码） |
| Barcode | `src/components/Barcode/index.vue` | 装饰性条形码，基于编号生成 |
| UploadButton | `src/components/UploadButton/index.vue` | 上传按钮组件 |

### 3. 组合式函数开发

| 组合式函数 | 文件 | 功能说明 |
|-----------|------|----------|
| useImageUpload | `src/composables/useImageUpload.ts` | 处理图片上传、读取 EXIF 数据 |
| useColorExtract | `src/composables/useColorExtract.ts` | 从图片提取主题色和候选色板 |
| usePhotoTransform | `src/composables/usePhotoTransform.ts` | 照片拖动和缩放逻辑 |
| useTicketExport | `src/composables/useTicketExport.ts` | 使用 html2canvas 导出 PNG/JPG |
| useMockData | `src/composables/useMockData.ts` | 生成 mock 数据（地点/时间/编号/随机码） |

### 4. 页面布局实现

- **电脑端**：左右分栏（`md:flex`），左侧票根预览 + 右侧编辑面板
- **移动端**：上下分栏（`flex md:hidden`），上方票根预览 + 下方编辑控制区
- 背景色动态跟随主题色，上传后自动切换

### 5. 关键功能验证

| 功能 | 验证结果 |
|------|----------|
| 图片上传 | 支持点击上传和拖拽上传 |
| EXIF 读取 | 自动提取拍摄时间和地点 |
| 主题色提取 | 自动提取并低饱和处理 |
| 候选色板 | 6 个色块，未上传时灰色空心圆圈，上传后彩色可点击 |
| 照片拖动/缩放 | 支持鼠标拖动和滚轮缩放 |
| 信息编辑 | 地点/时间/编号/随机码均可编辑 |
| 条形码 | 基于编号自动生成装饰性条形码 |
| 下载导出 | 支持 PNG 和 JPG 两种格式 |
| 响应式布局 | 桌面端和移动端布局自适应 |
