# 布纹背景板与 4:3 导出画框

- **日期**：2026-07-21
- **类型**：新增功能 + Bug 修复（多轮导出排障）
- **目标**：① 页面背景板从纯色改为布纹纸（linen）材质，票根本体纸质不变；② 导出票根时保留一定间距的背景板，整体为 4:3（适合自媒体信息流）；③ 导出保留投影增强实物感（后经多轮迭代放弃，最终导出无投影）

## 实现方案

- **背景板布纹**：`usePaperTexture` 的 `bakeTile`（颜色 × 灰度纹理正片叠底）复用到页面背景与导出画框，深色 `pageBgColor` 与 linen 灰度图烘焙成 tile 平铺；打孔齿孔孔体同步改为布纹采样，与背景板观感一体
- **4:3 导出画框**：离屏导出实例外套 1092×819 画框（票根 900px + 左右 96px 边距，上下约 218px），导出目标从票根本体改为画框
- **撕口导出后处理**：html2canvas 不支持 `mask-image`，导出 canvas 上用 mask 取反 + `destination-out` 补打缺口，再 `destination-over` 回填布纹背景（jpg 无透明通道）

## 排障记录（本次会话核心价值）

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 空态导出直接失败 | UploadButton 的 Tailwind v4 色值类编译为 oklch，html2canvas 无法解析 | 导出子树内颜色改 hex 任意值（`#99a1af`/`#6a7280`） |
| 导出票根无撕口 | html2canvas 1.4.1 完全不支持 `mask-image`，票根一直是矩形导出（历史遗留，本次加边距后才暴露） | 导出后处理 `applyTicketMask` 用 mask 位图补打缺口 |
| 后处理完全无效 | html2canvas 渲染完成后 ctx 残留 `scale + translate` 变换，后处理全画在画布外 | 绘制前 `setTransform(1,0,0,1,0,0)` 归位 |
| 缺口回填为纯色而非布纹 | 两次 `destination-over` 只有第一次生效（填充后缺口不再透明）；pattern 未按设备像素缩放 | 单次填充；`pattern.setTransform(scale(3))` |
| 缺口布纹是旧主题色 | 主题色连续变化时旧 tile 图片 onload 后到达，竞态覆盖新 tile | onload 时校验 url 与当前值一致才接受 |
| 左侧"双重撕口"（第一次） | 投影剪影用锐利 mask 生成，细小切口在投影边缘复刻出第二缺口列 | 剪影 `blur` 模糊侵蚀，消除缺口轮廓 |
| 左侧"双重撕口"（第二次） | 模糊剪影画进位图再擦除，外溢边缘擦不净，残留近黑描边 | shadow-only 技巧：剪影画在画布外，`shadowOffsetX` 移回投影，剪影不落地 |
| 投影"垫板感" | 四边对称强暗影在静态图上像垫了张深色卡纸 | 剪影收缩（blur 10px + alpha 增益）+ 阴影放大（blur 24/70） |
| 缺口变"亮斑" | 剪影收缩后缺口回填纯背景，缺口外背景被投影压暗，明暗断层 | 投影位图按缺口 mask 裁剪盖回缺口，内外投影连续；白底高对比验证通过 |
| 投影始终不理想 | 静态导出图上实物投影的强度/断层难以平衡 | **最终决策：导出去掉投影**，移除全部投影烘焙代码 |

## 关键代码

导出撕口后处理（`HomeView.vue` `applyTicketMask`）：

```ts
// mask 语义为「黑 = 保留，透明 = 镂空」，先取反得到「仅缺口处不透明」的冲孔层
invCtx.fillStyle = '#000'
invCtx.fillRect(0, 0, inv.width, inv.height)
invCtx.globalCompositeOperation = 'destination-out'
invCtx.drawImage(maskCanvas, 0, 0)

// html2canvas 渲染后 ctx 残留变换，必须归位再按设备像素绘制
ctx.save()
ctx.setTransform(1, 0, 0, 1, 0, 0)
ctx.globalCompositeOperation = 'destination-out'
ctx.drawImage(inv, x, y, w, h)
// 缺口回填画框布纹背景（jpg 无透明通道，镂空后必须回填，否则变黑）
ctx.globalCompositeOperation = 'destination-over'
ctx.fillStyle = pattern ?? pageBgColor.value
ctx.fillRect(x, y, w, h)
ctx.restore()
```
