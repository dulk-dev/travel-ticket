# 票根样式调整：裁剪线与镂空缺口

## 基本信息

| 项目 | 内容 |
|------|------|
| 任务类型 | UI 优化 / 新增功能 |
| 日期 | 2026-07-11 |
| 目标 | 为票根添加物理票根的拟真视觉效果：裁剪线分隔与镂空缺口 |

## 需求描述

用户要求对票根样式进行三项调整：

1. **左侧上传区域**：移除虚线边框，保持简洁界面
2. **编辑区与票根区分隔线**：使用粗虚线实现裁剪线效果，营造"可撕开"的感觉
3. **票根右侧半圆形缺口**：模拟现实中票根被工作人员剪口的效果，缺口需有镂空感（无阴影）

## 分析思路

### 裁剪线实现方案

调研了多种 CSS 虚线实现方式：
- `border-style: dashed` — 无法精细控制虚线节奏
- `repeating-linear-gradient` — 可精确控制实线段和间隔长度，推荐方案
- `border-image` + `repeating-linear-gradient` — 过于复杂

最终选择 `repeating-linear-gradient(to bottom, color 0px, color 6px, transparent 6px, transparent 12px)` 实现纵向虚线，6px实线+6px间隔的节奏感类似真实票根裁剪线。

### 半圆形缺口实现方案

尝试了多种方案：

| 方案 | 结果 | 问题 |
|------|------|------|
| 绝对定位圆形元素覆盖 | 不可见 | 外层 `overflow-hidden` 裁剪，且颜色对比不足 |
| `radial-gradient` 背景透明 | 不可见 | 信息区与票根背景色差异仅15%，透明效果不明显 |
| `clip-path: circle()` | 失败 | 将整个信息区裁剪为圆形，而非切出缺口 |
| `mask-image` + `radial-gradient` | **成功** | 在容器上创建透明圆形区域，真正镂空，阴影也被切掉 |

### 缺口尺寸

初始固定半径 18px，用户反馈后改为动态计算：
- 使用 `ResizeObserver` 监听票根容器高度
- 缺口直径 = 票根高度 / 5（半径 = 高度 / 10）
- 最小半径 18px，确保小尺寸下仍有可见效果

## 解决方案

### 1. 移除左侧上传区域虚线边框

**PhotoArea.vue**：移除无图片状态下的 `border-2 border-dashed` 类
**UploadButton/index.vue**：移除上传图标圆环的 `border-dashed` 类

### 2. 裁剪线分隔效果

在 `TicketCard/index.vue` 中新增裁剪线区域：

```vue
<!-- 裁剪线分隔效果 -->
<div class="shrink-0 relative flex items-center justify-center" :style="tearLineStyle">
  <div :style="tearLinePatternStyle"></div>
</div>
```

```typescript
const tearLineStyle = computed(() => ({
  width: '12px',
  height: '100%',
  backgroundColor: props.primaryColor,
}))

const tearLinePatternStyle = computed(() => {
  const isDark = textColor.value !== '#2C2C2C'
  const lineColor = isDark ? 'rgba(255,255,255,0.35)' : 'rgba(0,0,0,0.2)'
  return {
    width: '3px',  // 线条宽度（用户反馈后从 2px 加宽到 3px）
    height: '100%',
    background: `repeating-linear-gradient(
      to bottom,
      ${lineColor} 0px,
      ${lineColor} 6px,
      transparent 6px,
      transparent 12px
    )`,
  }
})
```

### 3. 右侧半圆形镂空缺口

使用 `mask-image` + `ResizeObserver` 实现动态镂空缺口：

```typescript
const ticketHeight = ref(0)
let resizeObserver: ResizeObserver | null = null

onMounted(() => {
  if (ticketRef.value) {
    resizeObserver = new ResizeObserver((entries) => {
      for (const entry of entries) {
        ticketHeight.value = entry.contentRect.height
      }
    })
    resizeObserver.observe(ticketRef.value)
  }
})

const ticketMaskStyle = computed(() => {
  const notchRadius = Math.max(18, Math.round(ticketHeight.value / 10))
  return {
    ...ticketBaseStyle.value,
    maskImage: `radial-gradient(circle at calc(100% + 2px) 50%, transparent ${notchRadius}px, black ${notchRadius + 1}px)`,
    WebkitMaskImage: `radial-gradient(circle at calc(100% + 2px) 50%, transparent ${notchRadius}px, black ${notchRadius + 1}px)`,
  }
})
```

## 遇到的问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 半圆形缺口不可见 | 外层 `overflow-hidden` 裁剪了超出边界的元素 | 改用 `mask-image` 在容器上直接切出缺口 |
| 缺口有阴影边缘 | 票根容器的 `shadow-2xl` 会投射到缺口处 | `mask-image` 会同时裁剪掉阴影，形成真正的镂空 |
| 缺口颜色对比不足 | 信息区背景色仅比票根亮15% | `mask-image` 透明区域露出的是页面背景色（比票根暗15%），对比度翻倍 |
| 固定尺寸缺口不适应缩放 | 不同窗口大小下票根高度变化 | 使用 `ResizeObserver` 动态计算缺口半径 |
