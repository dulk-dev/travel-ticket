# 票根分词Bug修复与布局优化

## 执行信息

- **任务类型**: Bug 修复 + 代码重构
- **日期**: 2026-07-11
- **目标**: 修复票根地点输入的分词错误，解决超长文字撑宽票根导致布局变形的问题

## 问题描述

票根地点输入存在两个核心问题：

1. **分词错误**：
   - 英文单词（如 "Japan"）被按字母数硬切，导致 "JA" / "PAN" 的奇怪分割
   - 中文地点（如 "成都"）的拼音被连成一个字符串后按字母数切割，丢失了汉字边界，导致 "CHEN" / "GDU"

2. **布局变形**：
   - 超长无空格字符串（如 "SingaporeSingapore"）会撑宽右侧信息区，导致整个票根比例变形，左侧照片区域被压缩

## 分析思路

### 分词问题分析

原有逻辑：
1. 中文：`pinyin(type: 'array')` 返回每个汉字的拼音数组，但用 `.join('')` 硬拼成字符串，丢失了汉字边界
2. 英文：直接过滤非字母后按字母数硬切，不考虑单词边界
3. 分割算法：按固定字母数 `switch-case` 机械分割，完全不考虑语义

### 布局变形分析

1. 使用 `transform: scale()` 缩小文字时，配合 `width: ${100 / scale}%` 意图保持视觉宽度不变
2. 但这实际上放大了元素占据的空间，导致父容器被撑宽
3. flex 布局默认 `min-width: auto`，右侧信息区无法缩小到比内容宽度更窄

## 解决方案

### 1. 语义单元分词算法

**核心思路**：保留语义单元（每个汉字的拼音 / 每个英文单词），按单元数均分到两行，而非按字母数硬切。

```typescript
// 中文：每个汉字对应一个拼音单元
const pinyinUnits = pinyin(cleanLocation, { toneType: 'none', type: 'array' })

// 英文：按空格分词，每个单词作为独立单元
const words = location.trim().toUpperCase().split(/\s+/).filter(w => w.length > 0)

// 分割算法：计算最佳分割点，使两行字符长度最接近
const totalLen = units.reduce((sum, u) => sum + u.length, 0)
let bestSplit = 1
let minDiff = Infinity
for (let i = 1; i < units.length; i++) {
  const firstLen = units.slice(0, i).reduce((sum, u) => sum + u.length, 0)
  const secondLen = totalLen - firstLen
  const diff = Math.abs(firstLen - secondLen)
  if (diff < minDiff) {
    minDiff = diff
    bestSplit = i
  }
}
```

### 2. 超长文字动态缩小

**核心思路**：使用 Canvas `measureText()` 预先测量文字宽度，不受 DOM 渲染状态影响。

```typescript
const measureTextWidth = (text: string, fontSize: number): number => {
  const canvas = document.createElement('canvas')
  const ctx = canvas.getContext('2d')
  if (!ctx) return 0
  ctx.font = `900 ${fontSize}px system-ui, -apple-system, sans-serif`
  const letterSpacing = fontSize * 0.12
  const metrics = ctx.measureText(text)
  return metrics.width + (text.length - 1) * letterSpacing
}
```

当文字宽度超过容器可用宽度（92%）时，通过 `transform: scale()` 等比例缩小，最小缩放比例限制为 0.5。

### 3. 布局变形修复

**核心思路**：在 `TicketCard` 的右侧信息区添加 `min-w-0`，让 flex 子元素可以缩小到任意宽度。

```html
<!-- 修复前 -->
<div class="flex-1">

<!-- 修复后 -->
<div class="flex-1 min-w-0">
```

同时移除 `width: ${100 / scale}%` 的错误做法，改为外层 `overflow-hidden w-full` 限制宽度。

### 4. 编辑逻辑调整

移除 `InfoEditor` 的 `disabled` 状态绑定，未上传照片时也可以编辑地点、时间、编号、随机码。

## 遇到的问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| `transform: scale()` 后元素仍撑宽父容器 | 使用了 `width: ${100 / scale}%` 放大元素宽度 | 移除该样式，改为外层 `overflow-hidden` 限制宽度 |
| flex 子元素无法缩小 | flex 默认 `min-width: auto` | 添加 `min-w-0` |
| Canvas 测量与 DOM 渲染不一致 | `scrollWidth` 受 `transform` 影响 | 使用独立 Canvas 测量，不受 DOM 状态影响 |
| Playwright 输入框自动填充干扰测试 | 浏览器保留历史输入 | 使用 `location.reload()` 重置页面状态 |
