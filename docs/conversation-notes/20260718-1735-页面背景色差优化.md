# 页面背景色与票根主题色色差优化

## 执行信息

- **任务类型**：UI 优化
- **日期**：2026-07-18
- **目标**：解决页面背景色与票根主题色过于接近、票根卡片在视觉上被背景"吞没"的问题

## 问题/需求描述

用户反馈：上传照片后，页面背景色与票根卡片颜色色差太小，整体看上去没能体现出票根卡片（附橙色主题下背景与卡片几乎融为一体的截图）。

## 分析思路

梳理颜色链路：

- 票根卡片底色 = 主题色 `primaryColor`（信息区再提亮 15%）
- 页面背景色 = `primaryColor` RGB 各通道 × 0.85（原 `HomeView.vue` 的 `pageBgColor`）

问题根源：RGB 等比压暗 15% 只轻微改变明度，色相/饱和度完全不变，导致背景与卡片"同色不同深"，视觉上糊成一片；尤其高饱和主题色（橙、黄）时整页都是大面积浓色，卡片轮廓消失。

## 解决方案

1. **页面背景改为 HSL 空间变换**：与主题色同色相，明度减半且封顶 38%、饱和度 × 0.65。背景变为深邃的暗色调（如橙色 → 深棕），与浅色票根形成强明度差，卡片自然凸显；降饱和避免大面积刺眼浓色。
2. **页面文字色跟随背景**：新增 `pageTextColor`，按页面背景亮度取对比色（背景加深后基本恒为米白 `#F5F0EB`），替换原先跟随主题色的 `textColor`——避免深背景上出现深色文字。
3. **保存按钮反相**：由"深色底 + 主题色字"改为"主题色底 + 对比字"，在深背景上保持 CTA 可见性。
4. **颜色工具函数复用**：`useColorExtract.ts` 的 `hexToRgb / rgbToHsl / hslToRgb / rgbToHex` 改为导出，避免在 HomeView 重复实现。

## 关键代码

```ts
const pageBgColor = computed(() => {
  // 页面背景与票根同色相，但大幅加深并降饱和，拉开明度差让票根卡片凸显
  const { r, g, b } = hexToRgb(primaryColor.value)
  const hsl = rgbToHsl(r, g, b)
  const bgL = Math.min(hsl.l * 0.5, 38)
  const bgS = hsl.s * 0.65
  const rgb = hslToRgb(hsl.h, bgS, bgL)
  return rgbToHex(rgb.r, rgb.g, rgb.b)
})

// 页面上文字颜色：跟随页面背景亮度取对比色（背景加深后基本恒为浅色文字）
const pageTextColor = computed(() => {
  const { r, g, b } = hexToRgb(pageBgColor.value)
  const brightness = (r * 299 + g * 587 + b * 114) / 1000
  return brightness > 128 ? '#2C2C2C' : '#F5F0EB'
})
```
