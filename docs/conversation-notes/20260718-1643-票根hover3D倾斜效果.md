# 票根 hover 3D 倾斜 + 全息高光效果

## 执行信息

- **任务类型**：新增功能
- **日期**：2026-07-18
- **目标**：用户在网上看到卡片式设计中「鼠标 hover 到卡片不同位置时呈现空间感」的效果，希望应用到票根卡片上

## 实现过程

### 问题/需求描述

用户对效果的描述较模糊（「hover 到卡片不同位置时模拟出空间感」）。先通过网上搜索确认该类效果的通用名称与形态，再与用户澄清。

### 分析思路

搜索确认该效果在前端圈称为 **3D Tilt / 3D 视差卡片**，实际包含四种子效果：

1. 3D 倾斜（Tilt）：卡片整体随鼠标位置翻转
2. 全息光泽（Glare）：高光/镭射反光跟随鼠标（宝可梦卡牌效果）
3. 分层视差（Parallax）：卡内元素分层移动形成景深
4. 聚光灯辉光（Glow）：鼠标位置光圈/边框发光

经 `AskUserQuestion` 澄清，用户确认为 **Tilt + Glare** 组合，应用到票根卡片。

### 解决方案

- 新增 `useCardTilt` 组合式函数：按指针相对卡片中心位置计算 `rotateX/rotateY`（最大 ±6°/±9°，`perspective(1000px)`）；hover 中 0.1s 快速跟随，离开/按压时 0.5s 缓动回弹。高光 = 径向白光（跟随指针）+ 低透明度彩虹斜向光泽（随指针水平位置偏转）。
- `TicketCard` 新增**倾斜包装层**承载 transform，票根本体（`ticketRef`）布局与导出路径不变；高光层加 `data-html2canvas-ignore`，避免烤进导出图片。
- 仅 `(hover: hover) and (pointer: fine)` 设备启用，移动端不受影响。
- 按住拖拽照片时卡片自动压平，避免与照片拖动手势冲突。

### 关键代码

```ts
const onMouseMove = (e: MouseEvent) => {
  if (!hoverEnabled || isPressed.value) return
  const rect = wrapperRef.value?.getBoundingClientRect()
  if (!rect || !rect.width || !rect.height) return
  const px = (e.clientX - rect.left) / rect.width
  const py = (e.clientY - rect.top) / rect.height
  rotateY.value = (px - 0.5) * 2 * maxTiltY
  rotateX.value = -(py - 0.5) * 2 * maxTiltX
  glareX.value = px * 100
  glareY.value = py * 100
  glareOpacity.value = 1
}
```

```html
<!-- 高光层：导出图片时忽略 -->
<div class="absolute inset-0 pointer-events-none"
     data-html2canvas-ignore="true" :style="glareStyle"></div>
```

## 遇到的问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 高光可能被烤进导出图 | html2canvas 会捕获票根内所有子元素 | 高光层加 `data-html2canvas-ignore`；倾斜放在包装层（导出目标 `ticketRef` 不变） |
| 拖拽照片与 hover 倾斜冲突 | 拖动照片时 mousemove 同时驱动倾斜 | 监听 pointerdown 置 `isPressed`，拖拽期间压平卡片 |
| 初始高光在浅色纸纹上太弱 | 径向白光 opacity 0.22 在米白/浅色票面上几乎不可见 | 验收截图确认后提升至 0.30，照片区效果清晰 |
| `type-check` 报 3 个错误 | `InfoArea.vue` 存量类型问题，与本次改动无关 | 确认非本次文件报错后放行，未顺带修改 |

## 验收（Playwright 驱动，证据见 `evidence/20260718-1610-card-tilt-glare/`）

- hover 左/右侧：rotateY ≈ ∓7.4° / ±7.1°，方向正确；左上/右下组合角度正确
- 高光渐变中心与指针位置一致；拖拽照片时 transform 为 identity（压平）
- 移出卡片回弹水平、高光 opacity 归零；导出图片水平且无高光
