# 票根编辑区域UI调整

## 执行信息

| 项目 | 内容 |
|------|------|
| **任务类型** | 功能调整 / UI优化 |
| **日期** | 2026-07-11 |
| **目标** | 简化票根编辑区域右侧控制面板，优化视觉层级，提升核心操作 prominence |

## 需求描述

对票根生成器右侧编辑控制区域进行以下调整：

1. 移除"票根信息"标题文字
2. 移除编辑区域底部的条形码组件（预览区已包含）
3. 将 PNG/JPG 两个下载按钮合并为单一按钮
4. 新增"重新上传照片"按钮
5. 弱化"重新上传照片"按钮的视觉表现

## 分析思路

### 关于下载格式的评估

- **JPG**：压缩率高、文件小、适合照片类内容，但不支持透明背景
- **PNG**：无损压缩、支持透明，但文件体积大

**结论**：选择 JPG 作为默认格式。票根以照片为主体，JPG 更利于社交分享；同时"保存票根"比"下载 PNG/JPG"对用户更直观。

### 关于按钮层级设计

"保存票根"是核心操作，应使用实心填充样式突出；"重新上传照片"是次要操作，使用边框+淡化样式避免抢夺视觉焦点。

## 实现过程

### 1. 移除标题与条形码

右侧编辑区域移除了包裹 `InfoEditor` 的 `<label>` 标签，以及独立的 `Barcode` 组件引用。

### 2. 合并下载按钮

将两个并排的下载按钮合并为单个全宽按钮：

```vue
<button
  @click="downloadTicket('jpg')"
  :disabled="isExporting"
  class="w-full px-4 py-3 rounded-lg font-medium text-sm ..."
  :style="{
    backgroundColor: textColor,
    color: primaryColor,
  }"
>
  {{ isExporting ? '导出中...' : '保存票根' }}
</button>
```

### 3. 新增重新上传按钮

添加隐藏的文件输入元素，通过 `triggerUpload` 方法触发：

```vue
<input
  ref="fileInputRef"
  type="file"
  accept="image/*"
  class="hidden"
  @change="handleUpload"
/>
```

```vue
<button
  @click="triggerUpload"
  :disabled="isExporting"
  class="w-full px-4 py-3 rounded-lg font-medium text-sm border ..."
  :style="{
    borderColor: textColor + '40',
    color: textColor + '99',
    backgroundColor: 'transparent',
  }"
>
  重新上传照片
</button>
```

### 4. 按钮视觉弱化

- 边框从 `border-2`（2px 实色）改为 `border`（1px），颜色透明度降至 25%（HEX alpha `40`）
- 文字颜色透明度降至 60%（HEX alpha `99`）
- 背景保持透明

## 遇到的问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 重新上传需要触发文件选择 | 原上传逻辑通过 TicketCard 组件内部处理 | 在 HomeView 添加隐藏 `<input type="file">`，通过 ref 调用 `click()` 触发 |
