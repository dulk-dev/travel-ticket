# 票根实物化缺口与照片内嵌改造验收

## 执行目的

参考实物票根照片，为票根新增四类形态特征：

1. 裁剪线位置上下两个小半圆缺口
2. 票根最左侧一个半圆大缺口（与右侧对称）
3. 左右两侧大缺口四周的成排细小切口（圆头短槽）
4. 左侧照片上传区域与票根边缘保持 padding 间距，照片区域圆角

## 关键改动（src/components/TicketCard/index.vue）

- 新增 `bakeTicketMask()`：将票根轮廓烘焙为位图 mask（Canvas，3x 分辨率，缓存按 `宽x高@照片占比` 键控）。
  单层 radial-gradient 无法表达复合镂空，位图 mask 一次成型：左右大半圆缺口（半径 max(18, H/10)）、
  裁剪线上下小半圆缺口（半径为大缺口一半，x = 照片占比 + 6px 对齐裁剪线条带中心）、
  左右边缘成排圆头短槽切口（绕开大缺口周围区域）。
- `ticketMaskStyle` 由单层 radial-gradient 改为烘焙位图 + `mask-size: 100% 100%`，
  首帧未测量高度时按 400px 逻辑高度烘焙避免闪跳。
- 新增 `photoRatio`（解析 photoWidth 百分比，桌面 65% / 移动 58% 均适用）、
  `photoPadding`（max(12, H×5.5%)）、`photoRadius`（max(10, H×4%)）。
- 照片区模板：外层容器加 padding，内层圆角 overflow-hidden 包裹 PhotoArea 与纸纹覆盖层。

## 验证方式

## 第二轮迭代（问题修正）

用户反馈两个视觉问题并给出目标图对照：

1. **大缺口裁到照片**：原大缺口半径 H/10（≈34px）超过照片 padding（5.5% ≈19px）。
   修正：大缺口半径降为 H×6%，照片 padding 提升为 max(14, H×7.5%)，保证缺口只落在纸边上，
   缺口与照片间始终留有纸边间距。
2. **细小切口不够细碎、形状单一**：原统一圆头短槽。
   修正：固定种子伪随机生成 —— 圆口 / 三角口 / 圆头短槽三种形状混合，
   尺寸（3.5%~6.5% H）、切入深度（1.8%~3.2% H）、位置均带抖动，
   30% 概率在切口内侧叠加微小毛刺缺口，模拟实物打孔的不规则毛边。

## 第三轮迭代（切口密度与三角口尺寸）

用户给出目标边缘特写图，反馈：小缺口数量要更多、三角形状缺口应更小。

修正（`bakeTicketMask` 切口生成逻辑）：

- 切口间距 H×9.5% → H×6.2%（密度提升约 50%），边缘起始 margin H×7% → H×6%
- 形状分布从三等分改为：圆口 50% / 三角口 25% / 圆头短槽 25%
- 三角口整体缩小：沿边尺寸 ×0.55、切入深度 ×0.7

## 第三轮验证

- `07-denser-slots.png`：彩色照片桌面端整体 + 左缘局部放大，
  切口密度与目标特写图一致，三角口明显小于圆口，形状/大小/位置保持不规则

## 第四轮迭代（切口秩序感）

用户反馈：目标实物的小切口整体「平衡对称」、深度一致，给人「多票相接、可沿切口撕开」的实物感，
毛刺仅 1-2 处点缀；而我们的切口大小深度参差、毛刺过多，像「被老鼠咬过」。

修正（`bakeTicketMask` 切口生成逻辑重写）：

- 取消圆头短槽形状，以半圆咬口为主，仅 15% 概率偶发小三角口（尺寸 ×0.6、深度 ×0.75）
- 尺寸波动收窄至 ±10%（4.2%~5% H），深度高度一致（2.2%~2.6% H），位置抖动收窄至间距 ±5%
- 整排切口参数预生成一次、左右两缘镜像共用，保证两侧对称
- 毛刺从「每个切口 30% 概率」改为「左侧固定 1 处 + 右侧 50% 概率 1 处」，
  位置随机落在某切口内侧，点缀实物感而不破坏秩序

## 第四轮验证

- `08-balanced-slots.png`：彩色照片桌面端整体 + 左缘局部放大，
  半圆咬口均匀一致、左右镜像对称，仅个别毛刺点缀，秩序感与目标实物图一致

## 第五轮迭代（去除毛刺）

用户反馈毛刺视觉效果不佳，决定暂时去掉。

修正：移除 `bakeTicketMask` 中的毛刺生成逻辑（`leftBurrRow` / `rightBurrRow` 及毛刺 punch），
切口仅保留半圆咬口 + 偶发小三角口，其余参数不变。

## 第五轮验证

- `09-no-burr.png`：左缘局部放大，切口均匀对称、无毛刺，边缘干净利落
